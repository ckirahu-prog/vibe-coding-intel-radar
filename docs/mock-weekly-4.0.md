### D1 值得研究的游戏 / 项目（≤3）

#### 暑期小品 · 一人+AI 完成章节（示例） {#d1-sword}

| 字段 | 内容 |
| --- | --- |
| 一句话背景 | 有人用常见编辑器 + AI + 引擎插件，几周做出可玩章节。 |
| 代表 | 示例 itch 项目 |
| 吸引力 | 可能吸引人的地方【判断】：完成度故事清晰，强调「有基础 + 工具」而非纯聊天。 |
| 单人+AI 可复用点 | 先做一个房间 + 一场战斗，对比有无引擎插件时多花的回合。 |
| 现实规模 | 数周可玩章节【估计】；不是大作。 |
| 不要照抄 | 不要假设零基础也能同进度。 |
