# 周报归档说明

放入本目录的文件**不参与** Automation 的「本期周号 / 上一期」选取。

| 文件 | 原因 |
|------|------|
| `2026-W29-premature-period-0713-0719.md` | 在尚无 `2026-W29` digest、且日历未进入该 ISO 周时，被旧规则（跟更大文件名跑）生成的抢跑稿；周期写成 07-13~19。已迁出。更早还有一份 3.0、周期 07-04~10 却叫 W29 的错标稿，见 git 历史。 |

**现行规则**：`W_this` = digest 最大周；无 digest 才用**运行日** ISO 周。禁止无 digest 时写未来周。

正常周报只放 `reports/weekly/YYYY-Www.md`。
