## A · 本周跟进台

> 这周该盯哪几条？按档位分流，不是作业清单。

### 本周试一试（≤2）

- **EditorEyeStandAlone**（技术 · 新出现）— 给 Unity（常用商业游戏引擎）里的 AI 助手装「眼睛和手」：用收件箱/回执文件下指令，带安全栏，不是 MCP（让 AI 调用外部程序的接法）服务。接下来怎么看：Asset Store / README 装进空工程，**只发一条 inbox 指令**（如创建空物体或改一个可见属性）并核对 outbox（≤4h）。 → [详情](#c-editoreye)
- **三国 SLG（给 Agent 玩）**（可玩切片 · 新出现）— 开源网页 SLG（策略占地打仗）：人与 AI 走同一套协议；可「复制给 AI」或用 `slg-mcp` 接入。接下来怎么看：**跑通一局最小循环**——接入助手 → 建城/练兵或攻一格 → 看排行榜分组是否写入（≤4h）。 → [详情](#d1-slg-agent)

### 继续观察

- **genshin-miliastra-mcp**（技术 · 新出现）— 非官方 MCP：让助手在《原神》千星奇域 UGC（用户自建关卡）编辑器里搭关、写节点图、自动试玩。接下来怎么看：仅当你本周本来就开着千星奇域时，盯「接上 → 改一处节点 → 跑一次试玩」；没玩 UGC 则不装。 → [详情](#c-miliastra)
- **Tripo Studio ↔ Codex 插件**（技术 · 新出现）— 把已有的 Tripo Studio（网页 3D 生模会员）接到 Codex（OpenAI 的编程助手），少付一份独立 API。接下来怎么看：盯有没有「生成一只 GLB → 落进工程目录」的第三方复现；未见则先只读帖，不迁全管线。 → [详情](#c-tripo)
- **EVEngine**（技术 · 新出现）— 轻量、脚本驱动、宣称可交给 AI 直接搭游戏的引擎 SDK。接下来怎么看：盯官方有没有「下载 SDK → 一屏可玩」最短路径；没有则不换主栈。 → [详情](#c-evengine)

### 先收藏
