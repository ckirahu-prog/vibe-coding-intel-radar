## A · 本周跟进台

> 这周该盯哪几条？按档位分流，不是作业清单。

### 本周试一试（≤2）

- **godot-mcp-enhanced**（技术 · 新出现）— Godot 4.5–4.7 的增强 MCP（让 AI 助手调用引擎的接法）：无头/编辑器/游戏桥三层，带录屏与逐帧校验。接下来怎么看：按 README 接到 Cursor 或 Claude Code（终端里的 AI 写代码助手），**只跑通一条动作**（例如建节点或截一帧验证），别一次开满 33 个工具（≤4h）。 → [详情](#c-godot-mcp-enhanced)
- **Picxel**（画面 · 新出现）— 参考图 → 可识别像素精灵：模型认主体，本地算法落格，导出 32/64/128 透明 PNG。接下来怎么看：用一张自己的参考图，**只出一张 32×32 精灵并拖进任意小品工程当占位**（≤4h）。 → [详情](#c-picxel)

### 继续观察

- **LovePilot（LÖVE2D MCP）**（技术 · 新出现）— 实时读状态、模拟输入、截图、热更 Lua。接下来怎么看：盯有没有「接上 → 对正在跑的小游戏点一下输入」的最短示例；本周主线已占 Godot MCP，**不并行装**。 → [详情](#c-lovepilot)
- **AetherFX**（画面 · 新出现）— 声称用 Agent（自动干活的 AI 程序）经 MCP 写游戏特效，带本地 GPU 预览与效果库。接下来怎么看：盯是否出现「导出一个特效文件 → 能进 Godot/Unity」的第三方路径；未见则继续旁观。 → [详情](#c-aetherfx)
- **ai-rpg-stage / OmniDebugLink / generator-assets**（技术 · 连续第 2 周）— 上期观察三项本周 digest 无实质回流。接下来怎么看：再无「只开 stage / 一条远程测试 / 单张精灵最短依赖」证言则标降温，不装。
