## A · 本周跟进台

> 这周该盯哪几条？按档位分流，不是作业清单。

### 本周试一试（≤2）

- **rigby2d**（技术 · 新出现）— 开源 2D 骨骼动画（把角色拆成可动部件再导出）：带 MCP（让 AI 助手调用外部程序的接法），可导出到 Godot 4（开源游戏引擎）。接下来怎么看：装好后**只做一次**「导入 1 张 PNG/PSD → 绑最少骨骼 → 导出到现有小品工程看能否动」（≤4h）。 → [详情](#c-rigby2d)
- **OpenRPGMaker**（技术 · 新出现）— 用自然语言描述，做像素风 JRPG（日式角色扮演）切片：贴图编辑、侧面战斗、浏览器可玩。接下来怎么看：**只生成一间可走场景 + 一场侧面战斗**，浏览器里能点完一回合就停（≤4h）。 → [详情](#c-openrpgmaker)

### 继续观察

- **NexusLink（NexusMCP）**（技术 · 新出现）— Unreal Engine（虚幻引擎）向 MCP 插件簇：读改蓝图/材质/资源、查日志；另有 VS Code / 桌面端。接下来怎么看：只有你本周真开 UE 工程时，才盯「连上实例 → 改 1 个可见资产 → 看日志回执」；否则只收藏链接。 → [详情](#c-nexuslink)
- **SpriteCanvas**（技术 · 新出现）— 作者自述：一张角色图生成待机/攻击精灵图（游戏用的一帧帧小图）并导出 JSON。接下来怎么看：盯有没有**非作者**的导入引擎短证言；未见前不换主素材管线。 → [详情](#c-spritecanvas)
- **Godot-Director**（技术 · 连续第 2 周）— 你选设计选项，助手在 Godot 4 落地并用一次检查证明。接下来怎么看：本周已试 rigby2d / OpenRPGMaker 则不必双开；只盯「选项 → 证明检查」是否仍有人复现。 → 见上期 `2026-W43` / 附录

### 先收藏
