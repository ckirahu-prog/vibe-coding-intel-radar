## A · 本周跟进台

> 这周该盯哪几条？按档位分流，不是作业清单。

### 本周试一试（≤2）

- **playtest-lab**（技术 · 新出现）— 给游戏配「试玩小组」：确定性机器人 + AI 人设试玩，输出优先级报告；支持 Web / Unity / Godot，并带 Claude Code（终端里的 AI 写代码助手）Skill 与零依赖 CLI。接下来怎么看：按 README **只跑一次 CLI 或 Skill，对任意最小可玩页/工程出一份短报告**（≤4h）。 → [详情](#c-playtest-lab)
- **Pyxel**（可玩切片 · 有重要更新）— Python 复古小引擎，自带像素画/地图/音效编辑器，近年再上 Show HN（Hacker News「我做了个东西」）。接下来怎么看：**装上并跑通官方示例一屏**，或用内置编辑器画一枚 8×8 精灵再播一声（≤4h）。 → [详情](#c-pyxel)

### 继续观察

- **claude-code-game-development（LibreSessionFlow 同簇）**（技术 · 新出现 · **双源**）— 面向 Claude Code 的游戏向插件包（Godot / Unity / Unreal 等）与会话生命周期插件同簇出现。接下来怎么看：盯「只启用 1 个引擎插件 → 改动一处场景/资源」的最短证言；别一次装 22+65。 → [详情](#c-cc-gamedev)
- **aurum-studio**（技术 · 新出现）— 本地游戏工作台：无头 MCP（让助手调用外部程序的接法）、Godot 4.7、玩法校验与 Windows 打包。接下来怎么看：盯有没有「接上 MCP → 验一局可玩」的第三方复现；未见则不迁全家到它。 → [详情](#c-aurum)
- **prompt-to-scene**（画面 · 新出现）— 用 MCP + Unity 编辑器桥：让 AI 在 Blender（3D 建模软件）做道具 → 放进 Unity → 校验导入。接下来怎么看：你若本周不做 3D 道具管线，**旁观**；有管线再验证「同一资产改一版能回写」。 → 附录弱信号

### 先收藏
