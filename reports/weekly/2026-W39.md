## A · 本周跟进台

> 这周该盯哪几条？按档位分流，不是作业清单。

### 本周试一试（≤2）

- **free-sound-effects-api**（技术 · 新出现）— 免版税音效搜索/流式播放，并带 MCP（让 AI 助手调用外部工具的接法），适合给小品补一声命中/脚步。接下来怎么看：按仓库说明装 API 或 MCP，**只搜并下载 1 条 SFX，拖进任意可跑小品听一声**（≤4h）。 → [详情](#c-freesfx)
- **Posting Puzzle**（可玩切片 · 新出现）— 把「邮寄对应问题」（字符串拼接能否对齐的理论题）收成可玩谜题，itch 可下。接下来怎么看：**通一关**，记下作者怎样把抽象规则压成「选牌→拼串→对错反馈」（≤4h）。 → [详情](#d1-posting-puzzle)

### 继续观察

- **Nexus Forge**（技术 · 新出现）— 自称用 Agent（能多步自动干活的 AI 程序）在 Godot（开源游戏引擎）无头模式里规划、写 GDScript、验到可玩原型。接下来怎么看：盯有没有「一句话设定 → 一个最小可玩场景」的第三方复现；未见则不装整套工作室。 → [详情](#c-nexus-forge)
- **Roblox Studio MCP 簇**（技术 · 新出现）— `mcp-forge-studio-bridge` 等：脚本/地形/资源双向同步。接下来怎么看：你若不用 Roblox（在线创作平台），**旁观即可**；若在用，再看「改一处灯光或脚本能回写编辑器」的最短证言。 → [详情](#c-roblox-mcp)
- **GamePanl**（画面 · 新出现）— macOS 上的独立游戏策划台：笔记、参考图、生图提示词、风格卡一键复制。接下来怎么看：等你本周真要批量写提示词时再装；本周主线已占音效试一试，**不并行装**。 → [详情](#c-gamepanl)

### 先收藏

- **Vibe Coding Production Kit**（工具 · 新出现）— 面向 AI 写代码助手的生产向工作流模板。接下来怎么看：你下一次要给小品定「完成标准 / 回归检查」时再打开仓库对照，不必本周改工具链。 → 附录弱信号
