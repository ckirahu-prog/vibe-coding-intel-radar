- **pico-8-mcp**（技术 · 新出现）— 让 AI 助手通过 MCP（让助手调用其他程序的接法）在 PICO-8（8 位风小游戏机）里改精灵图、音效，并做无头试玩/截图。接下来怎么看：按 README 接到 Cursor 或 Claude Code（终端里的 AI 写代码助手），**让它画一张 8×8 精灵并跑一次无头模拟**（≤4h）。 → [详情](#c-pico8-mcp)

### D3 可复制制作方法（≤2）

- **旧逻辑当规格，迁一屏就停**：对照 Amiga→Godot 文——每次只迁一个可验证动作（跳/射/推），跑通再下一块。
- **精灵改完立刻无头跑**：对照 pico-8-mcp——改完图就截一帧/跑模拟，别攒一周末才点运行。

### D4 不建议跟（≤2，一句）

- **自研 C# 引擎 + 自有脚本 + IDE 一体（ArcadeMaker）**：讨论可以，单人 8–12 周 demo 成本不对——先用成熟引擎交可玩包。https://github.com/ArcadeMakerSources/ArcadeMaker/tree/master
- **Steam 旧构建泄漏考古**：和「这周做出一局」无关，别占制作时间。

本周游戏向短结：引擎侧试 **pico-8-mcp 一张精灵**；制作侧跟 **Amiga→Godot 一屏切片**；Unity MCP 与 Workflow 工单流继续**只观察**。
