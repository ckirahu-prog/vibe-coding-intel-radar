> 这周该盯哪几条？按档位分流，不是作业清单。

### 本周试一试（≤2）

- **Wheel-Mcp**（技术 · 新出现）— Godot（开源游戏引擎）的 MCP（让 AI 助手调用外部程序的接法）服务：跑游戏、查场景与运行时、用断言/日志/截图验改动。接下来怎么看：接上 Cursor / Codex（偏写代码的 AI 助手）后，**只做一次**「改一处可见节点或脚本 → 运行 → 看断言或截图回执」（≤4h）。 → [详情](#c-wheel-mcp)
- **PixelDoll**（技术 · 新出现）— 2D 角色「纸娃娃」换装：用 PixelLab（AI 生像素图工具）生成对齐帧的装备层，再导出到任意引擎。接下来怎么看：**生成 1 件可替换装备层并导出**，拖进你现有小品工程看是否对齐（≤4h）。 → [详情](#c-pixeldoll)

### 继续观察

- **godot-ai-agent-rules / unity-ai-agent-rules**（技术 · 新出现）— 免费 Cursor rules + `AGENTS.md`：拦住助手写 Godot 3 旧 API 或乱编 Unity（常用商业游戏引擎）接口。接下来怎么看：盯有没有「丢进空工程 → 让助手写一段脚本 → 无 yield/onready 之类旧写法」的短复现；未见则先只读 README。 → [详情](#c-ai-agent-rules)
- **UnityMCP**（技术 · 新出现）— 另一路把助手接到 Unity 编辑器的 MCP 桥（写明 v10.3.0 等客户端）。接下来怎么看：盯「装桥 → 在编辑器里完成 1 次可见改动」第三方证言；本周已试 Wheel-Mcp 则不必并行开坑。 → [详情](#c-unitymcp)
- **mcp-game-asset-forge**（技术 · 新出现）— 用 MCP 把提示词打成游戏素材的 Python 工具集。接下来怎么看：盯「一条提示 → 落盘一张可用贴图/精灵」最短路径；文档不清则不接进主工程。 → [详情](#c-asset-forge)
